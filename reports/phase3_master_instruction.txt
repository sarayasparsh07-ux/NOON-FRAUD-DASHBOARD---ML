## 5.2 Evaluation metrics

**Required metrics**
- Fraud recall.

**Additional useful metrics**

- False positives.

## 5.3 Handle the small number of fraud cases responsibly

The referee set has only 65 fraudulent transactions.

A difference of a few detected cases can materially change recall.

Where feasible, calculate and report appropriate 95% confidence intervals for recall and precision. Use a suitable method for the small fraud sample, such as Wilson intervals.

For ranking metrics, suitable bootstrap confidence intervals may also be included.

Make it clear that these intervals reflect uncertainty from a finite test sample. Do not overstate statistical certainty.

A paired comparison using the same test transactions can be included as supplementary analysis where methodologically appropriate.

Do not turn a supplementary statistical test into a substitute for the assignment's required metrics.
