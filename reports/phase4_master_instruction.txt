## Important: Understand the actual model interface

Read the `FraudModel` class in `src/modeling.py`.

Its interface is different from the professor's example.

The custom model accepts a pandas DataFrame containing the original raw predictor columns.

It internally performs preprocessing, prediction and probability calibration.

Its methods are:

- `model.predict(X)` — returns the final binary classification using the stored threshold.
- `model.predict_proba(X)` — returns the calibrated fraud score.
- `model.threshold` — contains the frozen decision threshold.
- `model.feature_order` — contains the expected predictor-column order.

In this implementation, `predict_proba()` returns a one-dimensional fraud-score array. Do not assume it returns the conventional two-column array used by a standard scikit-learn classifier.

Do not manually apply `pd.get_dummies()` or reimplement the model's preprocessing.

Do not replace the stored threshold with 0.5.

Use the original raw feature values and let the saved model perform its own transformations.

# PART 6 — IMPORTANT MODEL LIMITATIONS AND RESPONSIBLE INTERPRETATION

The Phase 3 evaluation produced the following results for the selected model:

- Recall: 67.69%.
- Precision: 4.07%.
- F1: 0.077.
- True positives: 44.
- False positives: 1,036.
- Referee test-set fraud prevalence: 0.325%.

These findings must inform the application's presentation.

The model is an academic fraud-screening prototype, not a production-ready automated enforcement system.

Its output should be interpreted as a signal to assist human review.

In particular:

- A FRAUD verdict means the model has flagged the transaction for investigation.
- A LEGIT verdict means the model did not flag the transaction at its stored threshold.
- Neither result independently establishes whether a transaction is genuinely fraudulent.
- Do not automatically block an order, suspend an account, deny a refund, or take another enforcement action.
- Do not display an unsupported claim of operational effectiveness.

Include a short, professional disclaimer inside the application explaining these limitations.
